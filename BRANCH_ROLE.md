# Branch Role

`twin-prime-engine` is the curated release-facing twin-prime repo.

Use it for:

- canonical engine code
- release notes
- public benchmark claims
- the canonical paper copy

Do not use it as the scratchpad for one-off research experiments.

Experimental branch:

- `Newtheory`

Promotion rule:

- stable work from `Newtheory` can be promoted here
- duplicated shared files should be owned here, not co-evolved independently in both branches
